This is a beta fan translation for the version of 'Xuan-Yuan Sword: The Scar of Sky' released on steam on August 18th 2021.
The final readme will be more detailed.

Installation Process:
1. Purchase and install the game on steam from 'https://store.steampowered.com/app/1638220/'
2. Open the games properties in steam, under the general tab, set the language to Simplified Chinese.
3. Under installed files click 'Browse' to open your local directory.
4. Download the patch and copy its contents into the local directory, overwriting when prompted.

This build is the first version to feature Swordster's recompiled dll and redirected hooks.  This adds several subtle improvements, and a few major ones.
Check the included .ini file for the details and to adjust the settings presented.
